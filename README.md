# OWENS INDEX — 릭오웬스 최저가·재고 비교

**사이트: https://owens-index.pages.dev**

릭오웬스 공식몰과 해외 판매처 20곳의 상품을 매일 모아, 같은 상품(품번·색상)끼리 묶고 원화 최저가와 재고를 보여 주는 비공식 사이트입니다. 2026-11-09 기준 상품 3,304개입니다.

## 매일 자동으로 도는 파이프라인

Windows 작업 스케줄러가 매일 아침 아래 순서를 실행합니다. 커밋 기록의 `data YYYY-MM-DD`가 이 자동 갱신입니다.

```
daily.mjs ─ build.mjs   공식몰·판매처 상품 수집 → 품번·색상으로 같은 상품 묶기 (stores.mjs)
          ├ publish.mjs 사이트 데이터(data.js) · 최저가 기록(history.json) · 상품별 공유 페이지
          ├ vectors.mjs 새 상품 사진만 벡터로 변환 (사진으로 찾기)
          └ git 커밋·푸시 → Cloudflare Pages 배포
            수집 상품 수가 갑자기 줄거나 실패하면 텔레그램으로 알림
```

## 핵심 — 판매처마다 다른 품번 표기를 하나로 묶기

판매처마다 품번 쓰는 방식이 달라서(구분자, 색상 코드 위치, 시즌 표기 등) 같은 상품을 찾으려면 표기를 정규화해야 합니다. `stores.mjs`가 판매처별 규칙을 갖고, `node test.mjs`로 품번 읽기·매칭을 자체 점검합니다.

판매처는 다음 조건을 모두 만족하는 곳만 넣었습니다.
- 봇 확인 화면 없이 열린다.
- robots.txt가 막지 않는다.
- 품번이 있어 같은 상품인지 확정할 수 있다.

요청이 많다는 거절(429)이나 서버 오류가 나면 쉬었다가 다시 받고, 끝내 실패한 판매처는 그날 데이터에 실패로 표시합니다.

## 기능

| 기능 | 내용 | 파일 |
|---|---|---|
| 최저가·재고 | 재고가 있는 판매처 중 원화 최저가, 사이즈별 재고, 최저가 기록 | `build.mjs`, `publish.mjs`, `public/index.html` |
| 사진으로 찾기 | 상품 첫 사진을 MobileCLIP-S0로 512차원 벡터로 바꿔 두고, 브라우저에서 올린 사진과 비교 | `vectors.mjs` |
| 매장 지도 | 공식 매장·백화점·편집샵 좌표(OpenStreetMap Nominatim). 방문자 제보는 D1에 쌓이고 운영자가 텔레그램 서명 링크로 승인 | `places.mjs`, `functions/api/places.js`, `functions/api/review.js` |
| 요청사항 | 방문자 의견을 D1에 저장하고 운영자에게 알림. IP는 해시로만 저장 | `functions/api/feedback.js` |
| 관심 상품 알림 | 텔레그램에서 상품·사이즈를 등록하면 재고가 생기거나 최저가가 3% 넘게 내려갈 때 알림 | `bot.mjs` |

## 보안

- 비밀 값(텔레그램 토큰, 서명 키)은 로컬 `.dev.vars`와 Cloudflare 비밀 설정에만 있고 저장소에는 없습니다.
- D1 쿼리는 파라미터 바인딩을 쓰고, 승인 링크 서명은 길이 전체를 비교합니다(앞에서부터 맞춰 보는 공격 방지).

## 실행

```bash
npm install
node build.mjs      # 수집 → public/data.js
node test.mjs       # 품번 매칭 자체 점검
npx wrangler pages dev public   # 로컬 미리보기
```

## 한계

- 스케줄러가 개인 노트북에서 돌아서, 노트북이 꺼져 있으면 그날 갱신이 빠집니다.
- 판매처 사이트 구조가 바뀌면 그 판매처 수집이 깨질 수 있습니다.
- 비공식 팬 사이트입니다. 상품 정보와 이미지의 권리는 브랜드와 각 판매처에 있습니다.
